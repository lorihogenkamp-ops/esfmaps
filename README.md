# esfmaps
 Interactive maps of the Evolutionary Stress Framework — evidence architecture and terminology.

The maintained ESF Rosetta Map is in the canonical [esf-rosetta-map repository](https://github.com/lorihogenkamp-ops/esf-rosetta-map). [Open the interactive map](https://lorihogenkamp-ops.github.io/esf-rosetta-map/).

For version 2.0.0 (October 26, 2026), see the canonical repository’s [README](https://github.com/lorihogenkamp-ops/esf-rosetta-map/blob/main/README.md) for documentation and the archived release link, [ERRATA](https://github.com/lorihogenkamp-ops/esf-rosetta-map/blob/main/ERRATA.md) for citation and annotation corrections, and [CHANGELOG](https://github.com/lorihogenkamp-ops/esf-rosetta-map/blob/main/CHANGELOG.md) for version history.
